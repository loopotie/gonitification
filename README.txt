Math Notepad

Open index.html in a current browser, or upload the complete folder to any static web host.
The MathLive library and fonts are included locally; the page does not need a CDN or network access.
Drafts, saved notes, and folders are stored in this browser. Notes are listed in the left sidebar.

Keyboard:
- Enter: add a row; in normal writing mode the new row stays in normal writing mode
- Control+/ (Mac): toggle math and normal writing modes
- Backspace on an empty row in normal writing mode keeps that row in text mode
- Command+S (Control+S on Windows/Linux): save or update the current note
- Command+Shift+S: download a standalone .tex copy
- Command+Shift+O: import a .tex or .txt file
- Up / Down: move through the multiline document
- Backspace at the start of an equation row: remove that row
- As you add lower rows, the page scrolls smoothly to keep the active cursor near the center of the screen

Use + Folder to create folders; use the + beside a folder to create subfolders. Drag notes and folders into folders to organize them, and drag folders onto All folders to move them back to the top level.
